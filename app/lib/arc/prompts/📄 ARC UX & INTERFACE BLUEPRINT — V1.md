Purpose

Not a productivity app.
Not a dashboard.

🔥 ARC Core UX Philosophy
Principle	Meaning
Zero Cognitive Load	User never “figures out” the app
No Lists, Only Dialogue	Not todo lists — conversations
Emotionally Aware UX	Responds to motivation + state
Minimum UI	Maximum clarity
System Comes To User	Not “user goes into system”
Your past challenge with Notion, planners, templates:
❌ You must remember the system
ARC flips it:
✔ The system remembers YOU — and prompts you.

ARC does not show menus, it shows stages in your journey.
